=================================================
Instalación en Windows descartada: la Microsoft Store abre en blanco; winget -s msstore falla con
0x8a15005e (certificate pinning) y, tras el bypass temporal (luego desactivado), con 0x8007041d al instalar.
Descarga directa del .exe: bloqueada por Windows Defender (falso positivo documentado por ngrok).
Solución: opción B del README del profesor -> servicio "tunel" (imagen oficial ngrok/ngrok) en compose.yaml,
comando `http http://api:8000`, token desde .env, profile "tunel".

$ docker compose --profile tunel up -d tunel

Nota: en los dos casos el servidor responde 200 con los datos. CORS no bloquea la petición: es el NAVEGADOR
quien, sin esa cabecera, impide a la web leer la respuesta. Por eso CORS no es autenticación (enunciado §9).
